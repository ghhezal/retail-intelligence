# Retail Intelligence

A multi-branch computer hardware retail management system with inventory tracking, sales management, stock transfers, and sales analytics.

## About the Project

Retail Intelligence is a full-stack web application designed to manage the operations of a computer hardware retailer with three branches.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL (Neon)

## Features

- Product and inventory management
- Sales and POS system
- Supplier and purchase order management
- Stock transfers between branches
- Sales analytics dashboard

## Database Design

The PostgreSQL database contains 14 related tables covering products, inventory, suppliers, sales, purchases, and stock transfers.

## Project Status

Currently under development. The database structure and sample data scripts have been created. Backend and frontend development will follow.
